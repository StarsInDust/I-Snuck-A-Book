Music Album Cover Images
========================

This folder is for storing album cover images for the Music page.

Required Images:
----------------
1. DO-BAD-Cover.png - Album cover for "DO BAD" single
2. Space-Notes-Cover.png - Album cover for "Space Notes" album

Image Specifications:
---------------------
- Format: PNG (recommended) or JPG
- Dimensions: 600x600 pixels or larger (square format preferred)
- File size: Optimized for web (under 500KB per image)
- Quality: High resolution for clarity

Note: Make sure to name your image files exactly as listed above, or update 
the references in Music-Awedae.html if using different filenames.
